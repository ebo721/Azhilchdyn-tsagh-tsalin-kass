Урьдчилгаа цалин болон сүүл цалин нь тусдаа дэд цэс байна. Хоёр дэлгэцийн dashboard, шаардлагагүй тайлбар текстийг арилгаж, өргөн дэлгэцэд сар, үйлдэл, хайлт болон шүүлтүүрийг нэг мөрөнд байрлуулна.

**Why:** Хэрэглэгч “2 цалингийн цэсийн dashboard арилга, тайлбар текстүүд хэрэггүй” гэж засварлуулж, цомхон хоёр загварыг баталсан.

**How to apply:** Цалингийн дараагийн UI өөрчлөлтөд нийт дүнгийн карт, тусдаа тайлбар самбар нэмж болохгүй. Сарын хаалт/нээлтийг зөвхөн сүүл цалинд үлдээнэ. Загварын жишээ төлбөрийн үйлдлийг бодит олголттой андуурч оруулахгүй; одоогийн төлбөрийн дэлгэрэнгүй/засварын урсгалыг хадгална.
