---
name: Orval mixed parameter collisions
description: Avoiding duplicate generated parameter exports when combining path and query parameters.
---

For operations generated by this workspace's Orval configuration, avoid mixing path and query parameters when an equivalent path-only contract or separately named resource endpoint is practical.

**Why:** Both a DELETE with a required query parameter and a GET with an optional query parameter generated the same parameter type name for path and query exports, causing duplicate-export failures after otherwise successful code generation.

**How to apply:** Prefer validated path lookup dimensions or separately named resource endpoints. Preserve existing callers rather than renaming an established route merely to avoid a generator collision. Run normal code generation and library typechecking.
