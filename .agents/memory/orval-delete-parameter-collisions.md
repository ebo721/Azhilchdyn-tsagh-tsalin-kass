---
name: Orval DELETE parameter collisions
description: Avoiding duplicate generated parameter type exports for DELETE operations.
---

For DELETE operations generated by this workspace's Orval configuration, avoid mixing path and query parameters in one operation when an equivalent path-only contract is practical.

**Why:** A DELETE operation combining path parameters with a required query parameter generated the same parameter type name in both Zod output modules, causing a TypeScript duplicate-export failure after otherwise successful code generation.

**How to apply:** Encode the required lookup dimensions as validated path parameters for DELETE endpoints, then run the normal OpenAPI code generation and library typecheck.
