API endpoint-ууд (routes/journal.ts)
GET    /journal/entries              — жагсаалт (шүүлт: огноо, эх сурвалж (sourceType), данс, төлөв draft/posted/void)
GET    /journal/entries/:id          — дэлгэрэнгүй (мөрүүдтэй)
POST   /journal/entries              — гар аргаар journal entry үүсгэх (manual). Body: { date, description, lines: [{accountId, debit, credit, memo}] }. lib/journal-posting.ts-ийн postJournalEntry-г дуудна, sourceType: "manual".
PUT    /journal/entries/:id          — зөвхөн status="draft" entry-ийн мөрүүдийг засах боломжтой (posted/void-г засахгүй, 409 буцаа). Засварласны дараа дахин тэнцэл шалгаж, тэнцвэл автоматаар posted болно.
POST   /journal/entries/:id/void     — voidJournalEntry дуудна. Зөвхөн posted entry-г void хийж болно (draft entry-г шууд устгаж болно, void биш — учир нь ledger-д хараахан ороогүй).
GET    /journal/accounts/:id/ledger  — тухайн дансны бичилтийн жагсаалт (огноо, journal entry id, debit/credit, гүйсгэн үлдэгдэл — энгийн T-account харагдац). Зөвхөн posted мөрүүдийг тоол.
GET    /journal/trial-balance        — туршилтын баланс: данс тус бүрийн нийт debit/credit, үлдэгдэл (зөвхөн posted). Хариунд нийт дебит=нийт кредит эсэхийг тэмдэглэсэн `{ balanced: boolean, accounts: [...] }` бүтэцтэй буцаа.
